# Glossary

## Core Concepts

- **Luci**: Local activity recorder capturing screen text, OCR blocks, application usage, and audio transcripts.
- **Granola**: AI meeting notes application storing meeting notes, transcripts, and summaries.
- **Agent History**: Reflections, daily activity summaries, and agent task execution logs (e.g. `~/.Life` and `~/.fb-mode/runs`).
- **Arny**: Unified MCP server and CLI interface bridging Luci, Granola, and Agent History for AI assistants.
